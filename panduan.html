Panduan penggunaan

Mulai mengelola kelas dengan NetDQM

Ikuti panduan singkat untuk menyiapkan server, menghubungkan konsol guru dan agent siswa, lalu memakai fitur utama saat kelas berlangsung.

Pilih installer atau portable Baca tutorial Windows lengkap

1. Persiapkan jaringan lab

NetDQM terdiri dari satu server, satu konsol guru, dan agent pada tiap komputer siswa. Semuanya harus dapat berkomunikasi melalui jaringan lokal yang sama. Port bawaan adalah TCP 47800.

Gunakan alamat IP tetap atau DHCP reservation untuk server. Contoh alamat di panduan ini adalah 192.168.1.10; ganti dengan alamat server Anda. Jangan membuka port server langsung ke internet.

Unduh installer Windows untuk pemasangan biasa. Untuk mencoba tanpa instalasi, unduh ZIP portable, ekstrak ke folder tetap, lalu jalankan berkas aplikasi di dalamnya. Komputer Windows tidak perlu memasang Python.

2. Jalankan server

Server Linux

Ekstrak paket server Linux dan jalankan pemasang. Pemasang menyiapkan layanan systemd, konfigurasi, dan meminta password server.

tar -xzf NetDQM-Server-linux-x64.tar.gz
cd NetDQM-Server-*
sudo ./install-server.sh

Untuk memeriksa layanan, jalankan systemctl status netdqm-server. Firewall harus mengizinkan TCP 47800 dari subnet lab.

Server Windows

Jalankan installer Server, lalu buka NetDQM Server dari Start Menu. Pada pemakaian pertama, buat password server. Installer menambahkan aturan firewall TCP 47800.

Biarkan jendela server berjalan selama kelas. Simpan password dengan aman; konsol guru dan agent harus memakai password yang sama.

3. Hubungkan konsol guru

  1. Pasang atau ekstrak NetDQM Console di komputer guru, lalu jalankan aplikasinya.
  2. Isi alamat server dan port 47800.
  3. Masukkan password server, nama tutor, dan ID ruangan, misalnya LAB-A.
  4. Klik Hubungkan. Kartu komputer siswa tampil setelah agent tersambung.

Nama ruangan harus sama di server, konsol, dan semua agent yang ingin masuk ke kelas tersebut.

4. Hubungkan komputer siswa

  1. Pasang atau ekstrak NetDQM Agent di setiap komputer siswa.
  2. Jalankan agent, lalu buka ikon NetDQM di area notifikasi dan pilih Pengaturan.
  3. Isi alamat server, port, password, nama komputer, dan ruangan yang sama dengan konsol.
  4. Simpan pengaturan. Aktifkan autostart agar agent berjalan saat siswa masuk ke Windows.

Jika ikon tray tidak terlihat, periksa ikon tersembunyi di taskbar atau gunakan jendela kontrol agent.

5. Gunakan fitur kelas

FiturCara mulai
Pilih siswaKlik kartu siswa. Gunakan Ctrl+klik untuk memilih beberapa siswa atau kotak pencarian untuk menemukan komputer.
Lihat layarKlik dua kali kartu atau pilih Remote & Pantau. Aktifkan kontrol input hanya saat diperlukan.
Siaran layarPilih Siaran Layar, tentukan seluruh kelas atau siswa terpilih, lalu mulai siaran.
Chat dan fileGunakan tab Chat untuk mengirim pesan. Pilih siswa dan gunakan Kirim File untuk membagikan bahan ajar.
Kunci atau blankPilih komputer lalu gunakan tindakan Kunci Layar atau Blank. Lepaskan kunci setelah kegiatan selesai.
KuisBuka Kelola Kuis, buat pertanyaan pilihan ganda, simpan, lalu mulai kuis dan pantau jawaban.
AbsensiBuka Absensi untuk melihat kehadiran dan ekspor daftar ke CSV.
Uji koneksi, chat, file kecil, dan satu kuis di beberapa komputer sebelum memasang agent ke seluruh lab. Beri tahu siswa sebelum memakai kontrol layar atau aksi daya.

6. Jika komputer siswa tidak muncul

  • Pastikan server sedang berjalan dan dapat dijangkau dari jaringan lab.
  • Pastikan firewall mengizinkan TCP 47800.
  • Cocokkan alamat server, password, dan nama ruangan di semua komputer.
  • Mulai ulang agent setelah mengubah pengaturan.
  • Periksa panduan unduh untuk verifikasi checksum dan bantuan pemasangan.
